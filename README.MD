# TES DEBUGGING DIVISI IT - CULTURAL FESTIVAL

## Kasus
User melaporkan: "Saya mau daftar jadi panitia, tapi pas buka web, list pendaftarnya kosong. Pas coba daftar, tombolnya cuma loading atau error. Tolong benerin dong mas IT."

## Misi Kalian (45 Menit)
1. Buat project ini jalan di laptop kalian (Setup Environment).
2. Cari kenapa datanya gak muncul.
3. Cari kenapa gak bisa daftar (input data gagal).

## Cara Setup (Baca Baik-baik)

### 1. Jalankan Backend (Server)
Buka terminal, arahkan ke folder server:
cd server
npm install
npm run start

### 2. Jalankan Frontend (Tampilan)
Buka terminal BARU, arahkan ke folder client:
cd client
npm install
npm run dev
